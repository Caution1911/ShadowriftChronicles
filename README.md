# Shadowrift Chronicles

**Unity action-adventure game** featuring seamless dimensional phasing, Voidblade combat stances, Luna Loyalty system, 5 distinct realms, and Meta Quest VR support with hand tracking.

## Features
- Dual-layer Dimensional Phasing
- Three Voidblade stances (Ravager, Sentinel, Harmonist)
- Luna Loyalty system with multiple endings
- 5 Realm scenes + Reality Storm boss
- Meta Quest hand tracking gestures
- Full UI, audio, save system, and progression

## Setup
1. Open in Unity Hub (Unity 6000.3 LTS recommended)
2. Install required packages: XR Plugin Management, OpenXR, XR Interaction Toolkit, XR Hands, Input System, Addressables
3. Open `Assets/Scenes/MainScene` or any Realm scene
4. Build for Android (Meta Quest) or Windows

## Project Structure
- `Assets/Scripts/Core/` - GameManager, Phasing, Stance, Loyalty, Audio, Save
- `Assets/Scripts/Mechanics/` - Player, Enemies, Projectiles, Gestures
- `Assets/Scripts/UI/` - UI Manager, Main Menu, Ending
- `Assets/Scenes/` - Realm scenes

Created from the full Game Design Document collaboration.
